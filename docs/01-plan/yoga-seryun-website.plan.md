## 1. 배경과 목표

### 1.1 현황 진단 (리서치 결과)

- **업체**: 요가명상,세련 마곡나루점 — 서울 강서구 마곡중앙로 161-8 두산더랜드파크 A동 2층 217호. 마곡나루역(9호선·공항철도) 1번 출구 도보 4분. 월–토 10:00–22:00, 일요일 휴무. 문의 010-4985-0082.
- **리브랜딩 중**: "치유요가명상 마곡점"이 2026년 6월 "요가명상,세련"으로 재탄생. **7월 리뉴얼과 함께 커리큘럼 개편** — 웹사이트 오픈의 최적 타이밍.
- **브랜드 원형**: 세(世)+련(蓮) = "세상에 피어난 연꽃". 슬로건 **SR : A Space To Restore(회복을 위한 공간)**. 유튜브 채널 소개글의 "하루의 시작과 끝에 만나는 **오렌지빛 하늘**" 모티프, 실제 로비의 오렌지 벤치와 일치.
- **검증된 강점 (네이버 리뷰 85건 분석)**: ①선생님의 차분한 목소리·맞춤 지도(핸즈온) ②싱잉볼 이완 ③소수정예 4~5명 ④깔끔·아늑한 시설과 아로마 향 ⑤합리적 가격 ⑥체험 후 즉시 등록 전환 다수 ⑦"주변에 요가·명상원이 드문데 유일한 곳".
- **채널 현황**: 네이버플레이스(리뷰 85건, 예약 연동 완료) > 공식 블로그(글 4건) > 인스타그램(@yoga_seryun, 신규) > 유튜브 세련TV(개설 직후). **자체 웹사이트 없음.**

### 1.2 웹사이트의 역할 정의

한국 로컬비즈니스에서 **발견(Discovery)은 네이버플레이스와 인스타그램에서 일어난다.** 웹사이트가 검색 유입을 직접 따내는 구조가 아니다. 따라서 이 사이트의 역할은:

1. **전환 허브**: 플레이스·인스타 프로필 링크·카톡 공유로 들어온 "이미 관심 있는 사람"을 무료 체험 예약으로 밀어주는 마지막 설득.
2. **브랜드 각인**: 템플릿 요가원 사이트(modoo/imweb 일색인 국내 시장)와 격이 다른 첫인상으로 "여긴 다르다"를 3초 안에 전달.
3. **신뢰 집약**: 흩어져 있는 리뷰·강사·수업 체계·가격을 한 화면 흐름으로 정리.

[고정 헤더] 로고(세련) ─ 수업 · 시간표 · 가격 · 공간 · 오시는길 ─ [체험 예약] (스티키 CTA)

⑤ Teachers    — 원장(스네하) · 나영 · 시소 선생님
⑥ Voices      — 실제 수련자 리뷰 (전환 직전 신뢰 블록)

[플로팅] 카카오톡 문의 FAB (모바일: 전화 버튼 병행)

### 섹션별 콘텐츠 상세

**① Hero — "간판이 아니라 선언"**
- 헤드라인(안): **"세상에 피어난 연꽃처럼, 다시 나에게."** + 서브: "요가와 명상으로 회복하는 공간, 마곡나루 요가명상 세련" — 위치 키워드를 서브카피에 자연스럽게 포함(SEO 겸용).
- CTA 2개: `첫 수업 무료로 체험하기`(주 CTA → 네이버 예약 딥링크 `booking.naver.com/booking/6/bizes/1676272`), `수업 시간표 보기`(보조 → ④ 앵커).
- 신뢰 마이크로카피: "네이버 리뷰 85건 · 소수정예 4~5인 · 마곡나루역 4분" 한 줄.
- 비주얼: 실제 수련실 사진(흰 커튼의 간접광) 위에 시그니처 모션(§5.4) — 스톡 이미지 절대 금지.

**② Philosophy — 브랜드 스토리**
- 블로그의 실제 카피 재활용: "'스스로 돌볼 시간의 부재'…지금 나의 몸이 '나를 좀 돌보아주기를' 요구하고 있는 걸지도 모릅니다."
- 세(世)+련(蓮) 이름 풀이를 타이포그래피 연출로(한자 병기). "동작만을 추구하는 요가에서 벗어나, 명상의 일부로써 요가를" — 차별화 포지셔닝 문장.

**③ Classes — 수업 체계를 '자산'으로**
- 시간표 이미지의 5색 레벨 체계는 이 요가원의 숨은 경쟁력 → **레벨 1~5 세로 스펙트럼**으로 시각화:
  - Lv1 편안한 요가(남녀노소) → Lv2 힐링 요가+명상 → Lv3 근골격계·근막이완 테라피(오십견·허리통증) → Lv4 찬드라 나마스카라 전통요가(이완+속근육) → Lv5 수리아 나마스카라 전통요가(근력·체형 변화).
- 3계열 분류 카드: **명상**(싱잉볼·아로마 호흡·회복명상·근막 테라피) / **요가**(하타·빈야사·인요가·아쉬탕가·힐링하타) / **케어**(개인레슨·암테라피·숙면테라피·기업강의).
- 암테라피는 별도 서브블록으로 정중하게: "투병 중인 분들을 위한 회복 테라피 — 상담 후 진행합니다."

**④ Schedule — 이미지 시간표 탈피 (핵심 기능)**
- 국내 요가원 대부분이 JPG 시간표를 올린다. 여기서 **HTML 인터랙티브 시간표**로 확실히 격차:
  - 모바일: 요일 탭(월~토) → 해당 요일의 12:00/18:30/20:00 수업 카드 목록. "지금 기준 가장 가까운 수업" 자동 하이라이트.
  - 데스크톱: 주간 그리드 전체 표시.
  - 각 수업 셀에 레벨 색 도트 + 담당 강사(나영: 화·목 / 시소: 수·금) + 탭하면 수업 설명 팝오버.
- 하단 고정 안내: "수업 60분 · 시작 10분 전부터 10분 후까지 입실 가능 · 임산부와 뇌전증이 있는 분은 수업 전 강사 상담을 먼저 해주세요."
- 데이터는 JSON 하나로 분리 → 시간표 개편 시 파일 하나만 수정.

**⑤ Teachers — "수련자는 요가원이 아니라 선생님을 고른다"**
- 원장(스네하)의 창업 스토리를 1인칭 짧은 글로: "내 삶을 바꾸어준 요가와 명상을 안내하는 곳". 나영·시소 선생님은 담당 요일·수업과 짧은 소개(약력은 원장에게 확보 필요 — §9 콘텐츠 수급).
- 리뷰 최다 언급인 "차분한 목소리"를 살릴 장치: 추후 **10초 오디오/영상 인사** 삽입 슬롯 설계(2차 범위).

**⑥ Voices — 리뷰를 전환 장치로**
- 실제 네이버 리뷰에서 발췌 큐레이션(6~8개, 짧게): "1회 체험으로 방문하고 너무 좋아서 바로 등록했습니다" / "수업 한 번뿐인데 고질적인 편두통이 조금 나아진 기분" / "싱잉볼의 울림이 귀에 댕— 하고" / "21주차 임산부인데 무리 없이".
- 키워드 투표 수치를 데이터 비주얼로: 시설이 깔끔해요 55 · 맞춤 지도 45 · 선생님 실력 32… (자랑이 아니라 '사실'로 제시).
- 이 섹션 직후에 CTA 재등장 — 리뷰 읽고 마음 움직인 순간에 버튼.

**⑦ Pricing — 투명하게, 이벤트 우선**
- "가격 문의 주세요"는 전환 킬러라는 게 리서치 결론. 현재 진행 중인 **리뉴얼 사전등록 이벤트**를 그대로 공개: 주2회 3개월 40만 / 6개월 70만, 주3회 3개월 46만 / 6개월 80만, 1년 무제한 140만(선착순 10명).
- 환불·양도 조건 각주 명기. 이벤트 종료 대비 정가 표 전환 가능한 구조로 마크업.
- 무료 체험(예약비 1만원, 수업 참여 시 환불) 안내를 가격표 최상단에.

**⑧ Space — 사진이 곧 카피**
- 수련실(우드 마루·흰 커튼·세이지그린 매트·싱잉볼 선반), 로비(오렌지 벤치·아로마), 탈의실(아치문·락커 15칸) — 실사진 큐레이션 그리드. 캡션은 리뷰 문장으로: "교보문고 같은 아로마 향이 나요."

**⑨ Visit — 방문 장벽 제거**
- 지도(네이버 지도 링크 + 정적 지도 이미지), "마곡나루역 1번 출구 도보 4분".

## 5. 디자인 디렉션

### 5.0 기준선과 그 너머

Anthropic frontend-design 스킬의 핵심 원칙을 바닥선으로 채택: *Hero는 논지다 / 타이포가 인격을 만든다 / 구조는 정보다 / 모션은 의도적으로 / 대담함은 한 곳에만 / 실제 콘텐츠로 설계*. 단, 스킬이 명시한 **"AI 디폴트 룩 1번 = 웜크림 배경 + 고대비 세리프 + 테라코타 액센트"가 정확히 요가원 클리셰**라는 점을 인지하고, 아래처럼 의도적으로 비켜간다. 또한 스킬이 다루지 않는 사진 아트디렉션·한국어 타이포·전환 퍼널·로컬 SEO는 §6~8에서 별도 규정한다.

### 5.1 컨셉: "세상에 피어난 연꽃 (Lotus at Dawn)" — 화이트·핑크 라이트 테마

근거는 브랜드 실물에서: 이름 **세(世)+련(蓮) = 연꽃**(연꽃의 색은 흰색과 분홍), 흰 커튼의 간접광이 도는 밝은 수련실, 아치문·아로마·살구빛 쉬어 커튼 등 밝고 아늑한 실내, 그리고 로고의 무드. 순백이 아닌 **연꽃잎의 웜 화이트**를 바탕으로, 유채색은 **로터스 로즈(연꽃빛 핑크)** 하나만 쓴다.

레퍼런스로 받은 Mindloop 프롬프트(비디오 히어로 + liquid-glass + 스크롤 리빌 + fadeUp 스태거)의 **프로덕션 사양은 그대로 채택**하되 색·서체는 세련의 세계로 번안: 블랙 → **웜 화이트**, 화이트 텍스트 → **딥 플럼 잉크**, Instrument Serif 이탤릭 액센트 → 한글은 **마루부리+로터스 로즈 강조**, 영문은 Instrument Serif italic 유지. 대비를 담당하는 딥 톤 섹션(Voices·CTA)은 **저녁의 딥 플럼**으로 1~2곳만.

- 규율: 유채 액센트는 로터스 로즈 하나, 한 화면에 한 번. 보라·인디고·멀티 그라데이션 금지, 채도 높은 '핫핑크' 금지(연꽃빛은 항상 저채도·웜). 스크롤 여정은 밝은 새벽(Hero~Schedule) → 저녁의 딥 플럼(Voices) → 다시 밝음(Pricing~Visit) → 딥 플럼(Footer)으로 흐르는 **하루의 명도 곡선** — 단일 명도 화이트 사이트와의 차이점.

### 5.3 타이포그래피

| 역할 | 서체 | 비고 |
|---|---|---|
| 한글 디스플레이 | **마루부리(MaruBuri)** Light/Regular | 네이버 무료 부리체. 나눔명조보다 현대적, 붓의 温기. 헤드라인 전용 |
| 영문 디스플레이 | Cormorant 계열(무료) 또는 프로젝트 여력 시 Canela급 | 아이브로우·짧은 영문 병기 전용, 소문자 운용 |
| 본문/UI | **Pretendard** (variable, dynamic subset) | 가독 담당. 단 헤드라인에 쓰지 않음(국내 AI-tell 방지) |

- 한글 조판 필수: `word-break: keep-all; overflow-wrap: break-word;` 헤드라인 `line-height: 1.3~1.4`, 본문 `1.7~1.8`, `letter-spacing: -0.01em`.
- 타입 스케일: 모바일 기준 헤드 clamp(1.75rem→3.5rem). 숫자(가격·시간표)는 tabular-nums.

### 5.4 시그니처 요소 (대담함은 여기 한 곳에)

**"숨 쉬는 원(圓)"**: Hero의 헤드라인 뒤에 연꽃빛 원이 **분당 6회(들숨 4초·날숨 6초) 심박이 아닌 호흡 템포로** 아주 느리게 커졌다 작아진다 — 명상 호흡 그 자체를 모션으로. 스크롤하면 이 원이 연꽃 개화 선화(line-drawing)로 이어져 ② Philosophy의 세(世)·련(蓮) 풀이에 도킹. `prefers-reduced-motion` 완전 대응. 균일한 fade-in-everything, 바운스, 패럴랙스 남발 금지.

### 5.6 모션 & 비디오 시스템 (프로덕션 사양 — Mindloop 레퍼런스 이식)

| 요소 | 사양 |
|---|---|
| 진입 모션 | 재사용 `fadeUp(delay)` 헬퍼: `initial {opacity:0, y:20}` → `whileInView {opacity:1, y:0}`, `viewport {once:true, margin:"-100px"}`, `duration 0.6, easeOut`, 섹션 내 요소별 stagger delay. **호흡 템포 유지 위해 duration은 0.6~0.9s, 스프링·바운스 금지** |
| 히어로 비디오 | 풀뷰포트 autoplay·loop·muted·playsinline MP4. 하단 `h-64 bg-gradient-to-t from-background` 페이드로 배경에 용해. 소재: 커튼 사이 노을빛이 드는 빈 수련실 팬 샷 또는 싱잉볼 연주 클로즈업(§5.5 촬영 리스트). 촬영 전 임시: Coverr/Pexels 시네마틱 무료 푸티지(요가·노을·직물) → 오픈 전 실촬영 교체 |
| 스크롤 단어 리빌 | ② Philosophy에서 `useScroll`+`useTransform`으로 단어별 opacity 0.15→1 리빌. 텍스트: **"진흙을 뚫고 피어나는 연꽃처럼, 지치고 힘든 순간을 지나 끝내 피어나고마는 우리."** — "연꽃처럼", "끝내", "피어나고마는"만 foreground+노을색, 나머지 hero-subtitle 톤 |
| liquid-glass | Mindloop의 `.liquid-glass`(luminosity blend + blur 4px + 상하 화이트 보더 그라데이션 마스크) 그대로 채택하되 웜 틴트: `rgba(247,243,236,0.02)`. 적용처: 헤더 CTA, 이메일 아닌 **체험예약 pill**, 카톡 FAB, 시간표 요일 탭 |
| 세리프 액센트 | 헤드라인 핵심 1단어만 강조 — 영문 아이브로우는 Instrument Serif 400 italic("a space to restore"), 한글은 이탤릭이 없으므로 **마루부리 + `--accent` 컬러 + 미세한 크기 대비**로 등가 연출 |
| 버튼 인터랙션 | `whileHover scale 1.03 / whileTap scale 0.98`, 라운드 full CTA. 흰 버튼 = `bg-foreground text-background` |
| 섹션 비디오 | ⑧ Space에 `rounded-2xl aspect-[3/1]` 와이드 루프 영상(수련실 팬) 1개, ⑥/CTA 배경에 오버레이(`bg-background/45`) 덮은 루프 영상 1개. 영상 총 3개 이하, 각 3MB 이하로 압축(H.264 + poster), 모바일 세이브데이터 시 poster 이미지 폴백 |
| 고퀄리티 이미지 | §5.5 실사진에 통일 그레이딩(웜 WB·저대비·그레인 5% 미만) + AVIF/WebP. 아이콘·일러스트는 lucide-react 라인 아이콘과 연꽃 선화(자체 SVG)만 — 3D 목업·AI 일러스트 금지 |

### 5.5 사진 아트디렉션 (스킬 미포함 영역)

- **원칙: 100% 실사진.** 스톡·AI 이미지 1장이라도 섞이는 순간 이 사이트의 존재 이유가 무너진다.
- 촬영 리스트(원장 협조 요청): ①커튼 사이 자연광의 빈 수련실(히어로) ②싱잉볼 클로즈업(연주 손) ③수업 중 뒷모습(수강생 얼굴 비노출 — 초상권) ④아로마·소품 디테일 ⑤로비 오렌지 벤치 ⑥강사 프로필(자연광, 정면 아닌 수련 동작).
- 톤 보정 가이드: 웜 화이트밸런스, 살짝 낮은 대비, 필름 그레인 5% 미만 오버레이(수공예 질감 — AI-slick 반작용 트렌드). 아치형 프레임 마스크는 탈의실 아치문 실물에서 근거를 얻으므로 1~2곳만 절제 사용.
- 사진 확보 전 임시 오픈 시: 이미 확보된 플레이스 사진 사용 가능하나 저해상 컷은 duotone(pine×linen) 처리로 품질 편차 은폐.

## 7. 기술 계획

- **스택**: **React + Vite + TypeScript + Tailwind CSS + shadcn/ui + Framer Motion** (레퍼런스 프롬프트 사양 채택 — 스크롤 단어 리빌·liquid-glass·스태거 모션을 프로덕션 품질로 구현하는 데 적합). 정적 export로 배포. 수정 포인트는 `src/data/schedule.json`·`pricing.json`·이미지 폴더로 격리해 유지보수 범위 최소화. hls.js는 스트리밍 영상 도입 시에만 추가(기본은 MP4 셀프호스트로 충분).
- **호스팅**: Cloudflare Pages(무료·무제한 대역폭, 한국 체감 30~50ms). 도메인 후보: `yogaseryun.kr` / `seryun.studio` — 원장 확인 필요.
- **폰트 전송**: 마루부리·Pretendard 모두 **woff2 동적 서브셋**(unicode-range 분할) self-host 또는 jsDelivr. `preconnect` + `font-display: swap`. 한글 풀글리프(11,172자) 원본 파일 직접 로드 금지.
- **성능 예산**: 초기 로드 총 500KB 이하(폰트 제외), 이미지 AVIF/WebP + `loading="lazy"`, LCP 요소(히어로 사진) preload. Lighthouse 모바일 95+ 목표.
- **접근성 바닥선**: 키보드 포커스 가시화, 시간표 `<table>`+캡션 시맨틱, 색 도트에 텍스트 레벨 병기(색맹 대응), 명도 대비 AA, `prefers-reduced-motion`.
- **외부 의존성 원칙**: 서드파티 스크립트 0개 목표(분석 1개 예외). 카톡·네이버는 전부 링크 방식.

## 부록 A. 구현 빌드 프롬프트 (Mindloop 사양 → 세련 번안, 그대로 실행 가능)

> Build a soft, luminous one-page landing site called **"요가명상,세련 (SR : A Space To Restore)"** — a yoga & meditation studio in Magok, Seoul. Use React + Vite + TypeScript + Tailwind CSS + shadcn/ui + Framer Motion. Fonts: **Pretendard** (sans, body/UI), **MaruBuri** (Korean serif, headlines), **Instrument Serif** (Latin serif, 400 + 400-italic, English eyebrow words only). Theme: **warm white (lotus-petal) background, deep plum ink foreground, a single lotus-rose accent** — 화이트·핑크 계열로 밝은 수련실과 로고 무드를 반영. No purple/indigo, no multi-color gradients, no saturated hot pink. Korean text needs `word-break: keep-all`.
>
> **Design System (index.css, HSL values without hsl() wrapper)**
> `--background: 20 45% 98%` · `--foreground: 340 16% 22%` · `--card: 348 35% 96%` · `--card-foreground: 340 16% 22%` · `--primary: 340 16% 22%` · `--primary-foreground: 20 45% 98%` · `--secondary: 348 30% 93%` · `--muted: 348 20% 92%` · `--muted-foreground: 340 8% 46%` · `--accent: 346 42% 55%` · `--accent-foreground: 20 45% 98%` · `--accent-soft: 348 45% 90%` · `--sage: 100 12% 62%` · `--dusk-plum: 340 20% 16%` · `--border: 345 18% 89%` · `--input: 345 18% 86%` · `--ring: 346 42% 55%` · `--hero-subtitle: 340 12% 30%`
>
> **Liquid Glass**: Mindloop의 `.liquid-glass` 클래스 정의를 그대로 사용하되 라이트 테마용 웜 틴트: `background: rgba(255,251,249,0.35)`, 보더 그라데이션은 white 대신 `rgba(188,92,116,…)` 로즈 톤. 적용처: 히어로 CTA pill, 시간표 요일 탭, 문의 FAB.
>
> **Animation**: 동일한 `fadeUp(delay)` 헬퍼 (opacity 0/y 20 → 1/0, viewport once, -100px margin, 0.6s easeOut, staggered delays). 추가로 Hero 헤드라인 뒤에 **breathing circle**: 연꽃빛(accent, opacity 0.10~0.14) 원이 scale 1→1.12→1을 10초 주기(들숨 4s/날숨 6s)로 무한 반복, `prefers-reduced-motion`시 정지.
>
> **Page structure (top → bottom)**
> 1. **Navbar** — fixed transparent, px-6 md:px-24 py-4. Left: 연꽃 선화 SVG 로고 + "요가명상,세련". Center: [수업 · 시간표 · 가격 · 공간 · 오시는길] anchor links, text-muted-foreground hover:text-foreground. Right: liquid-glass pill CTA **"첫 수업 무료 체험"** → https://m.booking.naver.com/booking/6/bizes/1676272 (new tab).
> 2. **Hero** — full viewport, autoplay/loop/muted/playsinline MP4 배경(수련실 노을빛 팬 샷, 임시로 Coverr/Pexels 시네마틱 요가 푸티지, poster 필수) + 하단 h-64 gradient-to-t from-background. Content centered pt-28: 신뢰 라인 "네이버 리뷰 85건 · 소수정예 4~5인 · 마곡나루역 4분" (text-muted-foreground text-sm), 헤드라인 text-4xl md:text-6xl lg:text-7xl MaruBuri tracking-tight — **"세상에 피어난 연꽃처럼, 다시 나에게."** ("연꽃처럼"만 text-accent), 그 위에 Instrument Serif italic 아이브로우 "a space to restore". 서브: "요가와 명상으로 회복하는 공간, 마곡나루 요가명상 세련" (hero-subtitle 색). CTA 2개: 흰 pill "첫 수업 무료로 체험하기" (bg-foreground text-background rounded-full px-8 py-3, whileHover 1.03/whileTap 0.98) + ghost "시간표 보기" (#schedule 앵커). Breathing circle은 헤드라인 뒤 z-0.
> 3. **Philosophy** — pt-40 md:pt-56. useScroll+useTransform 단어별 리빌(opacity 0.15→1): "진흙을 뚫고 피어나는 연꽃처럼, 지치고 힘든 순간을 지나 끝내 피어나고마는 우리. '스스로 돌볼 시간의 부재'가 길어졌다면, 지금 나의 몸이 나를 좀 돌보아주기를 요구하고 있는 걸지도 모릅니다." (text-2xl md:text-4xl MaruBuri, 강조어 "연꽃처럼"·"끝내"·"피어나고마는"은 foreground+accent). 하단: 세(世)+련(蓮) 이름 풀이 2단 카드 (fadeUp stagger).
> 4. **Classes** — border-t border-border/30, py-32. Eyebrow "CLASSES" (text-xs tracking-[3px] uppercase muted). 헤드라인 "동작이 아니라, 명상으로서의 요가" ("명상"에 accent). 레벨 1→5 수평 스펙트럼 바(sage→accent 도트, 각 레벨 탭시 설명: Lv1 편안한 요가 / Lv2 힐링+명상 / Lv3 근막 테라피 / Lv4 찬드라 전통요가 / Lv5 수리아 전통요가) + 3계열 카드 grid md:grid-cols-3 (명상: 싱잉볼·아로마 호흡·회복명상·근막 테라피 / 요가: 하타·빈야사·인요가·아쉬탕가·힐링하타 / 케어: 개인레슨·암테라피·숙면테라피·기업강의). 카드에 아이콘 이미지 대신 연꽃/싱잉볼/손 라인 SVG.
> 5. **Schedule** (`#schedule`) — `src/data/schedule.json` 구동. 모바일: liquid-glass 요일 탭(월~토) → 12:00/18:30/20:00 수업 카드(레벨 색 도트+강사: 나영 화·목, 시소 수·금). 데스크톱: 주간 grid table. "지금 기준 다음 수업" 셀에 accent ring. 하단 고정 안내문: "수업은 60분이며 시작 10분 전부터 10분 후까지 입실 가능합니다. 임산부와 뇌전증이 있는 분은 수업 전 강사 상담을 먼저 해주세요."
> 6. **Voices** — 배경 `--dusk-plum` 딥 톤 반전(저녁의 명상 무드), 텍스트는 웜 화이트. 리뷰 키워드 수치(시설이 깔끔해요 55 · 맞춤 지도 45 · 선생님 실력 32 …) 가로 바 + 실제 리뷰 인용 6개 카드(§3-⑥ 발췌), 각 카드 fadeUp stagger. 섹션 끝에 CTA 재등장.
> 7. **Pricing** — 리뉴얼 사전등록 이벤트 표(주2회 3개월 40만/6개월 70만, 주3회 46만/80만, 1년 무제한 140만 선착순 10명) + 최상단에 "1회 무료 체험 — 예약비 1만원, 수업 참여 시 환불" 하이라이트 카드(accent border). 환불·양도 조건 각주.
> 8. **Space** — rounded-2xl aspect-[3/1] 루프 영상 1개 + 실사진 그리드(수련실/로비 오렌지 벤치/아치 탈의실), 캡션은 리뷰 문장. 사진 아치형 마스크는 최대 2곳.
