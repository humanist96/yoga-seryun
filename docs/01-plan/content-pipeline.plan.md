# Plan: 원소스 멀티채널 홍보 파이프라인 (릴스 · 네이버 블로그 · 유튜브 쇼츠)

> Feature: `content-pipeline` · Phase: Plan · 작성일: 2026-07-13

## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem** | 홍보 글 하나를 릴스·블로그·쇼츠에 올리려면 채널마다 포맷·톤·규격을 손으로 다시 만들어야 해서, 운영자(원장님) 혼자서는 지속 가능한 콘텐츠 발행이 어렵다. |
| **Solution** | 브로셔 텍스트 한 편을 소스 파일 하나로 넣으면, 브랜드 킷(사이트 룩앤필 승계)을 공유하는 채널 어댑터 3개가 병렬로 릴스 영상·블로그 포스트·쇼츠 영상을 생성해 업로드 직전 패키지로 떨어뜨리는 파이프라인을 구축한다. |
| **Function UX Effect** | 운영자는 글 한 편 작성 → `content/out/{슬러그}/` 폴더에서 채널별 완성본(mp4·md·캡션·해시태그·썸네일)을 꺼내 각 채널에 올리기만 하면 된다. |
| **Core Value** | 발행 비용을 1/3 이하로 줄여 주 1회 이상 꾸준한 멀티채널 노출 → 마곡나루 상권 내 인지도·무료체험 유입 증가. |

## 1. 배경과 보유 자산

### 소스 콘텐츠 (파일럿)
사용자가 제공한 브로셔 원문 — "인수 과정의 고난… 회원님들의 밝아진 얼굴… 비움과 채움이 있는 다정한 공간 / 아로마·싱잉볼·숙면 테라피·회복 테라피 / 문의 010-4985-0082 / 네이버 검색: 요가명상세련 마곡나루점"

### 재사용 가능한 자산 (이미 구축됨)

| 자산 | 위치 | 파이프라인에서의 역할 |
|------|------|----------------------|
| Remotion 영상 프로젝트 | `video/` — **이미 1080×1920 세로(9:16), 30fps**, 씬 8개, 원장님 육성·SFX, 폰트 로딩 | 릴스·쇼츠 렌더 엔진. 씬 컴포넌트(BreathingCircle 등)를 템플릿으로 재조립 |
| 엄선 갤러리 사진 9장 | `site/public/media/gallery/` (인물·중복 검수 완료) | 영상 배경, 블로그 본문 이미지 |
| 브랜드 필름 | `site/public/media/brand-film.mp4` (48초, 원장님 목소리) | 영상 클립 소스, 쇼츠 확장판 소재 |
| 사이트 디자인 토큰 | `site/src/index.css` (크림/플럼/연꽃 핑크, serif 타이포, 호흡·꽃잎 모션) | 브랜드 킷의 원천 |
| 문구 톤 | 사이트 카피("빛이 머무는 수련실", "다시 나에게" 등) | 채널별 카피라이팅 가이드 |

## 2. 파이프라인 아키텍처

```
[1. 소스]                [2. 브랜드 킷]              [3. 채널 어댑터 — 병렬]           [4. 산출 패키지]
content/source/           content/brand/
2026-07-신장개업.md   →    brand.md (톤·금칙어)    →   ┌ 릴스 어댑터 (15~30s)      →   content/out/{슬러그}/
  frontmatter:             tokens.ts (색·폰트)         ├ 쇼츠 어댑터 (30~60s)      →     reels.mp4 + caption.txt
  hook/body/keywords/      logo, 사진 인덱스           └ 블로그 어댑터 (SEO 장문)  →     shorts.mp4 + meta.txt
  cta/assets                                                                            blog.md + images/
                                                                                        checklist.md (업로드 절차)
```

### 레이어 1 — 소스 스키마 (`content/source/*.md`)
```yaml
---
slug: 2026-07-recovery-story
hook: "인수 과정의 고난은 여전히 진행형이지만 🤣"
core: "회원님들의 밝아진 얼굴을 배웅하는 순간으로 위로를 받습니다"
identity: "비움과 채움이 있는 다정한 공간"
offerings: [아로마, 싱잉볼, 숙면 테라피, 회복 테라피]
cta: { trial: "네이버 1회 무료체험", tel: "010-4985-0082", search: "요가명상세련 마곡나루점" }
assets: { photos: [hall-pastel, evening-circle, powder-room], film: brand-film.mp4 }
tone: 다정함 + 유머 한 스푼 (원문의 🤣 유지)
---
(본문 자유 서술)
```
- 소스는 채널 중립적으로 작성 — "무엇을 말할지"만 담고 "어떻게 보여줄지"는 어댑터가 결정

### 레이어 2 — 브랜드 킷 (`content/brand/`)
- `tokens.ts`: 사이트 CSS에서 추출한 색(크림 배경·플럼·연꽃 핑크·세이지), 폰트(명조 serif + 라틴 이탤릭), 모서리 라운드·그레인 텍스처
- `brand.md`: 카피 톤 가이드(존댓말·다정함·과장 금지), 필수 표기(상호·전화·위치), 금칙(가격 언급 금지 — 현 정책), 해시태그 풀(#마곡나루요가 #마곡요가 #싱잉볼명상 #요가명상세련 …)
- Remotion 쪽 `video/src/config/`와 사이트 `index.css`가 이미 같은 계열이므로 추출·정리만 하면 됨

### 레이어 3 — 채널 어댑터 (병렬 실행)

| | 릴스 (Instagram) | 쇼츠 (YouTube) | 블로그 (Naver) |
|---|---|---|---|
| 규격 | 9:16, 15~30초, 무자막 시청 대비 큰 타이포 | 9:16, 30~60초, 원장님 육성 활용 | 장문 1,200자+, 사진 6~8장, 지도·예약 링크 |
| 구조 | 훅(0-3s) → 공간 컷 몽타주 → 4가지 테라피 카드 → CTA | 릴스 확장판: 훅 → 스토리(인수 고난→위로) → 공간 → 테라피 → CTA | 제목(SEO) → 스토리 → 공간 소개(갤러리) → 테라피 4종 설명 → 무료체험 안내 → 오시는길 |
| 제작 방식 | Remotion `Reels` 컴포지션 렌더 | Remotion `Shorts` 컴포지션 렌더 (릴스와 씬 공유, 길이만 확장) | 마크다운 생성 + 브랜드 프레임 씌운 이미지 세트 |
| 텍스트 산출물 | caption.txt (캡션+해시태그 20개) | meta.txt (제목·설명·태그) | blog.md (그대로 붙여넣기 가능) |
| 채널 문법 | 첫 프레임이 썸네일, 3초 내 훅 | 제목이 검색 노출 좌우 — 키워드 전진 배치 | 키워드 "마곡나루 요가/명상" 제목·소제목 반복, 본문 유사문서 회피(원문 재작성) |

### 레이어 4 — 산출 패키지 & 업로드 (연동 제외)
- `content/out/{슬러그}/`: reels.mp4, shorts.mp4, blog.md, images/(프레임 처리된 6~8장), caption.txt, meta.txt, thumbnail.png, **checklist.md**
- checklist.md: 채널별 수동 업로드 절차(권장 발행 시간대: 릴스 평일 18-21시 / 블로그 오전 / 쇼츠 주말 포함, 커버 선택, 위치 태그 "마곡나루역", 고정 댓글 문구)
- **계정 연동(보류) 로드맵**: 릴스 → Instagram Graph API(비즈니스 계정 전환 필요), 쇼츠 → YouTube Data API(OAuth), 네이버 블로그 → 공식 발행 API 부재로 수동 or 브라우저 자동화. 연동 전까지는 패키지+체크리스트로 운영

### 실행 인터페이스
- 명령 한 번: "content/source/X.md 발행 준비해줘" → Claude가 어댑터 3개를 병렬 서브에이전트로 실행 → Remotion 렌더 2회 → out/ 패키지 완성
- 반복되면 `.claude/skills/publish/` 스킬로 승격해 `/publish {slug}` 한 줄로 실행

## 3. 파일럿 콘텐츠 기획 (제공된 브로셔 → 3채널)

### 릴스 시안 (24초)
| 구간 | 화면 | 자막 |
|------|------|------|
| 0-3s | 브랜드필름 클립(어두운→밝은 전환) | "인수 과정의 고난은 여전히 진행형이지만 🤣" |
| 3-8s | 갤러리 낮 전경 컷 2장 크로스페이드 | "회원님들의 밝아진 얼굴이 위로가 됩니다" |
| 8-14s | 숨 쉬는 원 모션 + 파스텔 매트 컷 | "비움과 채움이 있는 다정한 공간" |
| 14-20s | 4분할 카드 순차 등장 | 아로마 · 싱잉볼 · 숙면 테라피 · 회복 테라피 |
| 20-24s | 캔들/저녁 컷 + 로고 | "네이버 1회 무료체험 · 요가명상세련 마곡나루점" |

### 쇼츠 시안 (45초)
릴스 구조에 8-14s 구간을 원장님 육성 클립("동작만을 좇는 요가가 아니라…")으로 확장, 마지막에 시간표·위치(마곡나루역 도보 4분) 정보 추가

### 블로그 시안
- 제목: "마곡나루 요가 | 인수의 고난 속에서도, 회원님들 얼굴이 밝아지는 이유 — 요가명상세련"
- 목차: ① 요즘 세련의 이야기(스토리텔링, 원문 재작성) ② 빛이 머무는 수련실(사진 4장) ③ 네 가지 회복 테라피 각각 2~3문장 ④ 1회 무료체험 안내(예약 링크) ⑤ 오시는길(지도)
- 이미지: 갤러리 사진에 크림 여백+로고 프레임 적용(브랜드 통일감)

## 4. 구현 로드맵

| Phase | 작업 | 산출물 | 규모 |
|-------|------|--------|------|
| 1 | 브랜드 킷 추출 + 소스 스키마 확정 + 파일럿 소스 작성 | `content/brand/*`, `content/source/2026-07-recovery-story.md` | 소 |
| 2 | 블로그 어댑터 (텍스트+이미지 프레임) | blog.md 생성 규칙, 이미지 프레임 스크립트(sips) | 소 |
| 3 | Remotion 릴스/쇼츠 컴포지션 (기존 씬 재조립 + 자막 시스템) | `video/src/Reels.tsx`, `Shorts.tsx` | 중 |
| 4 | 패키징 + 업로드 체크리스트 + 병렬 실행 워크플로 | `content/out/` 파이프라인, `/publish` 스킬 | 소 |
| 5 (보류) | 계정 연동 자동 배포 | Graph API·YouTube API 연동 | 계정 확보 후 |

### Phase 5 보완 — 임시 테스트 계정 검토 결과 (2026-07-13)

**결론: AI가 임시 테스트 계정을 대신 생성하는 것은 불가.** 세 플랫폼 모두 아래 제약이 있다.

| 플랫폼 | 계정 생성 요건 | 대리 생성 가능 여부 |
|--------|---------------|---------------------|
| Instagram | 이메일/휴대폰 인증 + 봇 탐지(CAPTCHA). 자동화 생성은 Meta 약관 위반 | ❌ 불가 |
| YouTube (Google) | 휴대폰 본인 인증 필수 | ❌ 불가 |
| Naver | 실명 + 휴대폰 본인인증 필수 | ❌ 불가 |

**대안 경로 (권장 순)**
1. **지금 가능** — 산출 패키지 로컬 검수: mp4·블로그 원고·프레임 이미지가 업로드 직전 형태로 완성되므로 계정 없이도 결과물 품질 확인 가능 (이번 파일럿에서 수행)
2. **계정 생성 후 반자동 업로드** — 원장님 본인 명의로 계정 생성(플랫폼당 5~10분). 이후 이 세션의 Chrome 브라우저 자동화(claude-in-chrome)로 업로드 과정을 함께 진행 가능. 첫 테스트는 YouTube '일부 공개'·Instagram '보관용 임시 게시'로 리스크 없이 검증
3. **API 자동 배포(Phase 5)** — Instagram: 비즈니스 계정 + Facebook 페이지 연결 + Graph API / YouTube: OAuth + Data API(일 업로드 쿼터 유의) / Naver 블로그: 공식 발행 API 부재 → 항구적으로 반자동(브라우저 자동화) 유지

## 5. 리스크 / 결정 필요 사항

| 항목 | 내용 | 대응 |
|------|------|------|
| 가격 언급 | 현재 사이트에서 가격 제외 정책 | 브랜드 킷 금칙어에 등재 — 모든 채널에서 금액 미표기 |
| 인물 사진 | 브로셔 무드상 회원 얼굴 소재가 효과적이나 초상권 문제 | 검수 완료된 무인물 컷만 사용, 인물 필요 시 원장님 동의 컷만 |
| 네이버 유사문서 | 블로그가 릴스 캡션과 동일 문구면 저품질 위험 | 어댑터가 채널별로 문장을 재작성(복붙 금지 규칙) |
| BGM 저작권 | 릴스/쇼츠 인앱 음원은 렌더에 못 넣음 | 렌더는 무음+SFX, 음악은 업로드 시 인앱 추가(체크리스트에 명시) |
| 계정 부재 | 인스타·유튜브·블로그 계정 정보 없음 | Phase 5 보류, 산출물은 업로드 직전 형태로 완성 |

## 6. 완료 기준 (Acceptance Criteria)

- [ ] 소스 md 1개 → 명령 한 번으로 3채널 산출물이 `content/out/{슬러그}/`에 생성된다
- [ ] 릴스·쇼츠 mp4가 9:16 규격, 사이트와 동일한 색·타이포·모션 언어를 사용한다
- [ ] 블로그 md는 붙여넣기만으로 발행 가능한 완성 원고이며 릴스 캡션과 문장이 겹치지 않는다
- [ ] 각 패키지에 채널별 업로드 체크리스트가 포함된다
- [ ] 가격 정보가 어떤 산출물에도 노출되지 않는다
