# Plan: 현장 사진 갤러리 — "빛이 머무는 수련실" 개편 + Hero 교체

> Feature: `gallery` · Phase: Plan · 작성일: 2026-07-13

## Executive Summary

| 관점 | 내용 |
|------|------|
| **Problem** | 현재 "빛이 머무는 수련실" 섹션은 사진 2장뿐이라 실제 공간의 규모·분위기를 충분히 전달하지 못한다. Hero 배경도 동일 사진(studio-hall.jpg)을 재사용 중이다. |
| **Solution** | 현장 사진 20장을 감별해 중복·유사컷과 인물 노출컷을 배제한 엄선 8장으로 갤러리 섹션(그리드 + 라이트박스)을 구축하고, 가장 인상적인 컷을 Hero 대문 이미지로 교체한다. |
| **Function UX Effect** | 방문자가 수련실의 낮/저녁 분위기, 싱잉볼 세팅, 입구·파우더룸까지 클릭 한 번으로 크게 열람할 수 있다. 첫 화면부터 실제 공간의 밝은 인상을 준다. |
| **Core Value** | "사진보다 더 쾌적하고 커요"라는 리뷰를 시각적으로 증명 — 신규 방문자의 체험 신청 전환율 상승. |

---

## 1. 배경 / 현재 상태

- 소스 사진: `pictures/` 폴더, KakaoTalk 원본 20장 (전부 4000×3000, 장당 2.5~3.9MB — 웹 직접 사용 불가, 최적화 필수)
- 대상 섹션: `site/src/components/SpaceSection.tsx` — "빛이 머무는 수련실" (사진 2장 고정 그리드)
- Hero: `site/src/components/Hero.tsx` — `HERO_VIDEO_URL`이 빈 문자열이라 `/media/studio-hall.jpg` 이미지 배경이 렌더링됨 (video poster로도 동일 파일 참조)
- 스택: Vite + React 18 + Tailwind v4 + framer-motion (라이트박스도 추가 라이브러리 없이 framer-motion으로 구현)

### Hero 대문 선정

- **채택: 009** — 싱잉볼을 중심으로 좌우 대칭을 이룬 정면 뷰. 커튼으로 빛이 고르게 들어 밝고, 중앙이 비교적 정돈되어 텍스트 오버레이와의 궁합이 좋다. 거울 반사 무결 확인 완료.
- 최초 1순위였던 002는 거울 속 촬영자 반사가 확인되어 제외(그룹 A 전체 동일 사유).

## 3. 구현 계획

### Phase 1 — 이미지 파이프라인 (sips 활용)
1. Hero용: 002 → 2400px 리사이즈 + 품질 압축 → `site/public/media/hero.jpg` (~400KB 목표)
2. 갤러리용 8장: 1600px 리사이즈 → `site/public/media/gallery/*.jpg` (장당 ~200-300KB)
3. 라이트박스 확대용은 동일 파일 재사용 (별도 원본 서빙 없음, 총 추가 용량 < 2.5MB)
4. EXIF 회전값 베이크(015·016 세로컷) 확인

### Phase 2 — GallerySection 컴포넌트 (SpaceSection 대체)
- `site/src/components/GallerySection.tsx` 신규 작성, `App.tsx`에서 교체 (`id="space"` 유지 → 네비게이션 앵커 보존)
- 섹션 타이틀 "빛이 머무는 수련실"과 하단 안내문(매트·소도구/락커) 유지
- 레이아웃: 모자이크 그리드 (가로 6장 + 세로 2장 혼합, 3열 기준 masonry 느낌) + `loading="lazy"`
- 라이트박스: framer-motion `AnimatePresence` — 클릭 확대, ←/→ 키보드·버튼 내비게이션, ESC/배경 클릭 닫기, 캡션 표시, 모바일 스와이프
- 접근성: 각 사진 한국어 alt, 라이트박스 `role="dialog"` + 포커스 관리

### Phase 3 — Hero 교체
- `Hero.tsx`의 배경 `src`와 video `poster`를 `/media/hero.jpg`로 교체
- 기존 `studio-hall.jpg`는 og.jpg 등 다른 참조가 없는지 확인 후 유지(안전) — 삭제하지 않음

### Phase 4 — 검증
- `npm run build` 통과 (tsc 포함)
- 브라우저에서 갤러리 열람 플로우·Hero 렌더링·모바일 뷰포트 확인
- 이미지 총량·LCP 체감 확인

## 5. 완료 기준 (Acceptance Criteria)
