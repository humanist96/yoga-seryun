## 1. 목표와 포맷

- **1차 산출물**: 45~50초 세로(9:16) 브랜드 홍보 영상 1편 — 인스타 릴스, 유튜브 쇼츠, 카톡 공유용
- **파생(2차)**: 15초 컷다운(광고용), 16:9 가로판(네이버 플레이스 동영상 슬롯) — 씬 재조합으로 생성
- **톤**: 홈페이지와 동일한 "연꽃빛 새벽" — 차분한 호흡 템포. 빠른 컷·비트 드랍 금지, 명상하듯 흐르는 편집
- **목표 행동**: 영상 끝에서 "첫 수업 무료 체험" — 프로필 링크(홈페이지) 유도

| 자산 | 상태 | 비고 |
|---|---|---|

| 카피·리뷰 | ✅ 확보 | 홈페이지 카피 + 네이버 리뷰 85건 발췌 (계획서 v1 §3-⑥) |
| **원장님 음성** | ⚠️ 추출 필요 | 세련TV 쇼츠 y6ess6ZH9NY ("2026년 2월 24일", 채널 @SeryunTV). 로컬 yt-dlp 구버전 오류 확인 → `brew install yt-dlp`로 최신화 후 추출 (P1) |

## 3. 오디오 설계 (모션과의 동기화가 핵심)

### 3.1 내레이션 파이프라인
1. `yt-dlp -x --audio-format wav`로 쇼츠 오디오 추출 → `public/audio/voice/raw.wav`
2. 전사(Whisper) → 문장별 타임스탬프 확보
3. **문장 단위로 클립 분할** (`voice/v01.wav`, `v02.wav`…) — 씬과 1:1 매핑, 재배치 자유
4. 원본에 BGM이 섞여 있으면 보컬 분리(demucs) 후 사용
5. 영상 대본에 필요한 문장이 원본에 없으면: (a) 자막+타이포로 대체 (b) 원장님 추가 녹음 요청 — **TTS로 원장 목소리 합성은 하지 않음**(동의 없는 음성 복제 배제)

### 3.2 사운드 레이어 규칙
| 레이어 | 내용 | 볼륨 |
|---|---|---|
| Voice | 원장 내레이션 (씬별 클립) | 0dB 기준 |
| BGM | 앰비언트 1트랙, 인트로 페이드인 3초·아웃트로 페이드아웃 | 평시 -14dB, **내레이션 구간 -22dB 더킹** |
| SFX | 모션 이벤트와 프레임 동기 | -8dB |

### 3.3 SFX ↔ 애니메이션 동기 맵
| 모션 이벤트 | SFX |
|---|---|
| 오프닝 로고 개화 / 씬 대전환 | 싱잉볼 "댕—" (긴 여운, 영상 전체에서 3회만) |
| 헤드라인 워드 리빌 | 극히 부드러운 breath-whoosh |
| 꽃잎 낙하 시작 | 없음 (침묵이 세련) |
| 리뷰 카드 등장 | 페이퍼 슬라이드 (미세) |
| 엔드 CTA 등장 | 밝은 chime 1회 |

## 4. 씬 구성 (콘티) — 총 48초 / 1440프레임 @30fps

| # | 씬 ID | 시간 | 비주얼 & 모션 | 내레이션(안) · 자막 | SFX |
|---|---|---|---|---|---|
| 1 | `S01Hook` | 0–4s | 딥 플럼 화면 → 싱잉볼 파동이 퍼지며 연꽃빛으로 밝아짐 | (음성 없음) 자막: "오늘, 나를 돌본 적 있나요?" | 싱잉볼 ① |
| 2 | `S02Brand` | 4–10s | 연꽃 로고 선화가 그려지고(개화) 숨 쉬는 원 등장 | 원장 육성 v01 + 자막: "세상에 피어난 연꽃처럼, 다시 나에게." | breath-whoosh |
| 3 | `S03Empathy` | 10–17s | 웜 화이트 배경, 워드 리빌(웹과 동일 모션) + 꽃잎 낙하 시작 | 원장 육성 v02: "'스스로 돌볼 시간의 부재'…" 계열 문장 | whoosh(미세) |
| 4 | `S04Space` | 17–24s | 수련실 실사진 켄번즈(줌인) → 아치 탈의실 크로스디졸브, 글로우 오버레이 | 원장 육성 v03 + 자막: "마곡나루역 4분, 회복을 위한 공간" | 앰비언트 상승 |
| 5 | `S05Classes` | 24–31s | 수업명 태그 스태거(싱잉볼 이완명상·하타·빈야사·인요가·근막테라피) + 레벨 5색 도트 스펙트럼 | 자막 중심: "레벨 1부터 5까지, 오늘의 컨디션대로" | 페이퍼 슬라이드 |
| 6 | `S06Voices` | 31–38s | 딥 플럼 반전, 실제 리뷰 2개 인용 카드 + "네이버 리뷰 85건" 카운트업 | 자막: "싱잉볼의 울림이 귀에 댕—" / "체험하고 바로 등록했어요" | 싱잉볼 ② (여운 짧게) |
| 7 | `S07Offer` | 38–44s | 연꽃빛 배경, "첫 수업 무료 체험" 필 버튼 + 숨 쉬는 원 재등장 | 원장 육성 v04(있으면) + 자막: "예약비 1만원, 참여 시 전액 환불" | chime |
| 8 | `S08Endcard` | 44–48s | 로고 + "요가명상,세련" + 주소·프로필 링크 안내, 꽃잎 잔상 | (음성 없음) 자막: "@yoga_seryun · 프로필 링크에서 예약" | 싱잉볼 ③ 페이드아웃 |

*내레이션 v01~v04는 P1에서 원본 음성을 전사한 뒤 실제 문장에 맞춰 재배정한다 — 위 문안은 자막 폴백을 겸하는 초안.*

## 5. Remotion 아키텍처 — "편집 용이성" 설계

```
video/                             # site/와 분리된 독립 패키지
├── package.json                   # remotion, @remotion/cli, @remotion/media-utils
├── public/
│   ├── audio/
│   │   ├── voice/ v01.wav …       # 문장 단위 원장 음성 클립
│   │   ├── sfx/   bowl.wav whoosh.wav chime.wav paper.wav
│   │   └── bgm/   ambient.mp3
│   └── images/                    # 웹사이트와 동일 사진
└── src/
    ├── Root.tsx                   # 컴포지션 등록부
    ├── config/
    │   ├── timeline.ts            # ★ 씬 순서·길이(프레임)·전환 — 단일 편집 지점
    │   ├── script.ts              # ★ 씬별 자막 텍스트·음성 클립 경로·시작 오프셋
    │   └── theme.ts               # 웹 index.css에서 가져온 컬러·폰트 토큰
    ├── lib/
    │   ├── sceneTiming.ts         # timeline.ts를 읽어 각 씬의 from/duration 자동 계산
    │   └── audio.ts               # 더킹·페이드 헬퍼
    ├── components/                # 웹에서 포팅한 재사용 모션 조각
    │   ├── BreathingCircle.tsx  Petals.tsx  WordReveal.tsx
    │   ├── GlowBackground.tsx   Caption.tsx  LotusLogo.tsx  KenBurns.tsx
    └── scenes/
        ├── S01Hook.tsx … S08Endcard.tsx   # 씬당 파일 1개, 텍스트는 전부 props
```

**편집 시나리오별 수정 지점** (요청사항 반영):
| 하고 싶은 편집 | 수정 위치 |
|---|---|
| 씬 길이 늘리기/줄이기 | `config/timeline.ts`의 `durationInFrames` 숫자 1개 — 뒤 씬들은 자동 밀림 |
| 씬 순서 변경·삭제 | `timeline.ts` 배열 순서 |
| 자막·문구 교체 | `config/script.ts` |
| 음성 클립 교체·타이밍 | `script.ts`의 `voice` 경로·`offsetInFrames` |
| 색·폰트 | `config/theme.ts` |
| 특정 씬만 미리보기/렌더 | 씬마다 개별 `<Composition id="S04Space">` 등록 → Remotion Studio에서 씬 단위 확인, `npx remotion render S04Space`로 단독 렌더 |

**마스터 컴포지션**: `Promo48` (1080×1920) — `timeline.ts`를 순회하며 `<Sequence>`로 씬을 배치, `<Audio>`로 voice/BGM/SFX 트랙을 프레임 오프셋에 깐다. 15초 컷다운 `Promo15`는 같은 씬을 부분 재사용(S01·S02·S07·S08)한 별도 컴포지션.

## 6. 비주얼 포팅 가이드 (웹 → Remotion)

- 웹 CSS keyframes는 Remotion에서 `useCurrentFrame()` + `interpolate()`/`spring()`으로 재구현 — 호흡 원은 10초 주기 sine 보간(들숨 4s/날숨 6s), 꽃잎은 씬 로컬 프레임 기반 낙하(웹 config 배열 재사용)
- 폰트: 마루부리·Pretendard woff2를 `@remotion/google-fonts` 대신 로컬 `staticFile` 로드 (마루부리 영상 사용 가능 라이선스 — 눈누 기준 재확인 1회)
- 자막(Caption): 하단 1/3, 마루부리 44px, 배경 blur pill — 음성 구간과 프레임 동기
- 안전 영역: 상단 200px(쇼츠 UI)·하단 320px(릴스 UI) 텍스트 배치 금지
